# DecodeLabs — Project 2 (Sales EDA)

A small exploratory data analysis (EDA) pipeline for a sales/orders dataset. This project loads the dataset, computes summary statistics, detects outliers, produces a few charts, and creates a final Excel report with summary sheets and visualizations.

## Contents of this folder
- `Dataset for Data Analytics (4).xlsx` — original dataset used for analysis
- `DecodeLabs_Project2_Final.xlsx` — output workbook produced by `final_report.py` (created by the pipeline)
- `eda_analysis.py` — EDA script that computes stats, detects outliers, and creates charts
- `final_report.py` — script that compiles results and visualizations into a formatted Excel workbook
- `EDA_Project.py` — placeholder / minimal file (empty or unused)

## What this project does
- Loads the sales dataset (orders with fields such as `OrderID`, `Date`, `Product`, `Quantity`, `UnitPrice`, `ItemsInCart`, `TotalPrice`).
- Prints dataset shape, columns, datatypes, missing values, and duplicates.
- Produces descriptive statistics and distribution summaries for numeric variables.
- Detects outliers using the IQR method (per-variable).
- Computes product-level summaries (orders, quantity, revenue, average order value).
- Computes monthly and yearly sales aggregates.
- Generates visualizations:
  - Monthly revenue trend (line plot)
  - Total revenue by product (horizontal bar)
  - Total price distribution (histogram)
  - Correlation heatmap
- Exports a final formatted Excel report (sheets: Raw Data, EDA Summary, Visualizations, Key Findings) using `openpyxl`.

## How to run

Important: both scripts currently reference absolute Windows file paths. Before running, either:
- Move the dataset file to the working directory and update file paths in the scripts; or
- Edit the `file_path` / `folder` variables in the scripts to point to the dataset location on your machine.

Quick steps:

1. Run the EDA script to inspect data and generate charts:

```bash
python eda_analysis.py
```

This prints summary output and saves:
- `revenue_by_product.png`
- `total_price_distribution.png`
- `correlation_heatmap.png`

(and displays the monthly revenue plot when run interactively)

2. Create the final Excel report:

```bash
python final_report.py
```

This script reads the dataset and produces `DecodeLabs_Project2_Final.xlsx` (an EDA workbook containing raw data, summary tables, visualizations, and key findings). It also expects the chart image files created by `eda_analysis.py` to be present in the configured folder.

Notes:
- If you want a single-step pipeline, run `eda_analysis.py` first to generate visualizations, then `final_report.py`.
- Both scripts can be modified to accept a command-line dataset path or use a relative path for smoother usage.
